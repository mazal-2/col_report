# 看剧剧场 Q3 复盘指标说明

## 一、消耗规模指标

| 指标 | 说明 |
|------|------|
| **Q3 总消耗** | Q3 季度广告消耗总额，单位为"w"（万） |
| **日均消耗** | 季度内平均每日消耗量 |
| **季度环比** | 本季度 vs 上季度消耗增长率 |
| **单剧日峰值** | 单个剧集在某一天达到的最高消耗 |
| **ROI** | 投入产出比，ROI>1 表示盈利 |

---

## 二、流量资源指标（IAP 视角）

| 指标 | 说明 |
|------|------|
| **大盘硬广** | 大盘（行业整体）硬广渠道带来的流量/消耗 |
| **软广** | 软性广告，流量结构之一 |
| **激励视频** | 以激励形式触发的视频广告 |
| **搜索** | 搜索渠道流量 |
| **看剧剧场软广低 Xpp** | 看剧剧场软广占比较大盘低 X 个百分点 |
| **付费成本** | 获取一个付费用户的平均成本 |
| **人均付费次数** | 付费用户平均付费次数 |
| **ARPPU（人均付费 ARPPU）** | Average Revenue Per Paying User，每付费用户平均收入 |
| **付费率** | 观看用户中转化为付费用户的比例 |

---

## 三、剧集分析指标

| 指标 | 说明 |
|------|------|
| **剧数量 vs 消耗倍差** | 剧集数量与消耗规模的倍数关系差异（Top1 分销 vs Top2/3 分销对比） |
| **爆款剧「首发能力」** | 剧集上线后前 3 天内获取流量的能力 |
| **「剧集覆盖」** | 有消耗的剧集占总剧集的比例 |
| **20w+ 分销剧市占** | 消耗 20w 以上分销剧的消耗占比 |
| **有消耗剧覆盖比** | 有实际消耗的剧集数量 / 总剧集数量 |
| **消耗占比分布** | 不同消耗量级剧集的数量占比（如 30%+、20%+、10%+） |

---

## 四、基建指标

| 指标 | 说明 |
|------|------|
| **活跃账户数** | 日均在投、余额>0 的账户数量 |
| **活跃非相似素材数** | 日均投放的非重复素材数量（去重相似素材后） |
| **活跃素材重复度** | 重复素材占总素材的比例，越低越好 |
| **剧集倍差** | 自身基建 vs 头部客户的差距倍数 |
| **峰值日 top1 活跃账户数** | 消耗最高那天活跃账户数最高的客户的账户数 |
| **峰值日 top1 活跃非相似素材数** | 消耗最高那天活跃非相似素材数最高的客户的素材数 |
| **峰值日 top1 新建非相似素材数** | 消耗最高那天新建的非相似素材数 |
| **账户活跃度** | 活跃账户占所有账户的比例（看剧 3%、其他 10%-50%） |
| **素材活跃度** | 活跃素材占总素材的比例（看剧 0.9%、其他 5%-10%） |

---

## 五、面板指标

| 指标 | 说明 |
|------|------|
| **面板金额** | 商品库设定的最低付费面板金额 |
| **小额面板** | 较低金额的付费面板 |
| **超小额面板** | 最低档位的付费面板 |
| **中额剧豆面板** | 中等金额的剧豆付费面板 |
| **头部账户面板趋势** | 高消耗账户偏好的面板金额档次 |

---

## 六、生命周期指标

| 指标 | 说明 |
|------|------|
| **前 3 天首发能力** | 剧集上线前 3 天抢量的能力 |
| **20 天后基建** | 剧集上线 20 天后剩余的基建规模（账户+素材） |
| **30 天后基建** | 剧集上线 30 天后剩余的基建规模 |
| **二次起量** | 剧集生命中期再次获得流量提升 |
| **三次起量** | 剧集生命后期再次获得流量提升 |
| **独家二次/三次起量机会** | 因生命周期长而获得的额外起量机会 |

## 九、常见计算公式

```
日均消耗 = Q3总消耗 / 季度天数
季度环比增长率 = (本期消耗 - 上期消耗) / 上期消耗 × 100%
付费率 = 付费人数 / 总观看人数 × 100%
ARPPU = 总付费金额 / 付费人数
有消耗剧覆盖比 = 有消耗剧集数 / 总剧集数 × 100%
活跃素材重复度 = 重复素材数 / 总素材数 × 100%
```
