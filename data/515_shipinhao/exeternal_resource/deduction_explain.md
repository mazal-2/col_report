## 二、权重系数推导

### 基本假设
- **转发**：强传播行为，带来新用户，权重最高
- **推荐**：认可行为，平台会推流，权重次之
- **点赞**：门槛最低，价值相对较小，权重最低

### 推导过程

设公式为：
```
播放量 = k × (w1×点赞 + w2×转发 + w3×推荐)
```

根据行业标准经验值，设定权重比例：
- 点赞 w1 = 1（基准）
- 转发 w2 = 13（约13倍点赞价值）
- 推荐 w3 = 3（约3倍点赞价值）

代入基准样本数据：
```
12,256 = k × (1×32.25 + 13×9.21 + 3×30.71)
12,256 = k × 245.1
k = 50.2 ≈ 50
```

### 最终公式
```
播放量 ≈ 50 × (点赞 + 13×转发 + 3×推荐)
收益   ≈ 播放量 × 5.75元/万播放
```

---

## 三、权重合理性说明

| 指标 | 权重 | 说明 |
|------|------|------|
| 点赞 | 1 | 门槛低，大量用户会随手点赞，价值最低 |
| 转发 | 13 | 需要用户主动分享，传播价值最高 |
| 推荐 | 3 | 平台推荐机制的核心指标，价值中等 |

权重设计体现了不同互动行为的**传播价值差异**：
- 转发一次 ≈ 13次点赞的播放贡献
- 推荐一次 ≈ 3次点赞的播放贡献

**注意**：权重≠直接播放比例。完整公式为：
```
播放量 = 50 × (1×点赞 + 13×转发 + 3×推荐)
```
其中 **50** 是单位系数（每单位加权互动对应的播放量）。

### 计算示例

以《开局被抢墨麒麟》为例：
```
加权互动值 = 600 + 13×354.4 + 3×433.1 = 6,506
播放量 = 50 × 6,506 = 325,312
收益 = 325,312 × 0.000575 = 187.05元
```

## 五、注意事项

1. **样本局限**：仅基于1个参照样本推导，误差可能较大
2. **账号差异**：不同账号的粉丝基数、内容质量会影响转化率
3. **时效性**：互动数据为快照，播放量持续增长
4. **适用范围**：本公式适用于视频号动态漫类目的粗略估算
