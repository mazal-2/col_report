# 数据分析报告写作指南

本文档定义如何撰写一篇标准的视频号运营数据分析报告。

---

## 一、报告整体框架

```
标题：{账号名}视频号 {月份}运营分析报告
数据周期：{开始日期} — {结束日期}

内部分析
│
├── 第一部分：内容倾向
│   ├── （一）日频趋势
│   ├── （二）周频趋势
│   ├── （三）月频占比
│   └── （四）特定样本分析
│
├── 第二部分：受众情况
│   ├── （一）年龄分布
│   └── （二）性别分布
│
└── 第三部分：运营方式
    ├── 3.1 上架节奏
    └── 3.2 原创账号与二创账号对比（可选）
```

---

## 二、核心指标定义

| 指标 | 定义 | 计算方式 |
|------|------|----------|
| 播放量/阅读量 | 内容被观看的总次数 | 直接统计 |
| 广告收益 | 广告分成收入 | 直接统计（注意单位：分/元） |
| 万播收益 | 每万次播放的收益 | 广告收益 / 播放量 × 10000 |

---

## 三、内容倾向划分维度

### 维度一：频道（男女频）
- **女频**：女性向内容，通常都市言情、甜宠等
- **男频**：男性向内容，通常玄幻、末世、热血等

### 维度二：题材
- **都市**：现代都市背景
- **玄幻**：奇幻/修仙/异能等
- **末世**：末日生存/丧尸/灾难等
- **其他**：根据实际内容补充

---

## 四、各部分写作规范

### 第一部分：内容倾向

#### （一）日频趋势

**数据准备：**
1. 按日期聚合每日的广告收益、播放量
2. 分别按「频道」和「题材」两个维度拆分
3. 计算每日万播收益

**图表输出：**
- 图1：男女频日频趋势（折线图，双Y轴：收益+万播收益）
- 图2：题材日频趋势（折线图，双Y轴：收益+万播收益）

**文字描述模板：**
```
以下展示{月份}（{开始日期}-{结束日期}）每日广告收益与万播收益的趋势，
按男女频和题材两种维度分类。可观察到{趋势特征}，
万播收益波动反映变现效率的日间变化。

[插入图1]

女频因基数大主导整体趋势，男频万播收益更高说明变现效率更优。

[插入图2]

都市内容占据主导，但玄幻题材万播收益显著更高，说明小流量也能有高变现。
```

---

#### （二）周频趋势

**数据准备：**
1. 将月份划分为自然周（如 W1:4/1-5, W2:4/6-12...）
2. 按周聚合收益数据
3. 分别按「频道」和「题材」维度统计

**图表输出：**
- 图3：男女频周频对比（柱状图）
- 图4：题材周频对比（柱状图）

**文字描述模板：**
```
将{月份}划分为{N}个自然周（W1:..., W2:..., ...），
聚合每周的广告收益与万播收益。整体呈{走势描述}，
W{N}因{原因}达到峰值。

[插入图3]

女频在W{N}达到峰值，男频在W{N}小幅回落但效率更稳定。

[插入图4]

都市内容W{N}爆发后回落，玄幻在W{N}逆势上扬，说明题材间存在互补效应。
```

---

#### （三）月频占比

**数据准备：**
1. 全月汇总各频道/题材的总收益、总播放量
2. 计算占比

**图表输出：**
- 图5：男女频月频占比（饼图，收益+播放量双饼）
- 图6：题材月频占比（饼图，收益+播放量双饼）

**文字描述模板：**
```
{月份}全月汇总，广告收益与阅读量的占比分布。

[插入图5]

女频收益{金额}元（占比{X}%，阅读量{Y}%），仍是绝对主力；
男频收益{金额}元（占比{X}%，阅读量{Y}%），万播收益达{Z}元/万播，
远超女频的{W}元/万播，说明男频用户变现效率显著更优。

[插入图6]

都市收益{金额}元（占{X}%），玄幻{金额}元（{Y}%），末世{金额}元（{Z}%）；
但万播收益方面，玄幻>都市>末世，与收益规模呈反向关系，
说明小众题材反而变现效率更高。
```

---

#### （四）特定样本分析

**数据准备：**
1. 按剧目汇总收益、播放量、万播收益
2. 分别取广告收益Top3、播放量Top3、万播收益Top3
3. 标注每个剧目的频道和题材

**表格输出：**
- 表1：广告收益Top3剧目
- 表2：播放量Top3剧目
- 表3：万播收益Top3剧目

**文字描述模板：**
```
1，按剧目划分：分别选取广告收益、阅读量、万播收益三项指标各前3名

[插入表格]

2，关键样本描述

广告收益最高：{剧名}，总收益{金额}元，总阅读量{数量}，万播收益{效率}元/万播。
该剧为{频道}{题材}题材，{时间段}开始起量，{后续表现描述}。

阅读量最高：{剧名}，总阅读量{数量}（全月最高），但总收益仅{金额}元，
万播收益{效率}元/万播，变现效率仅为{对比剧}的{比例}，存在高流量低变现问题。

万播收益最高：{剧名}（{频道}{题材}），总收益{金额}元，总阅读量{数量}，
万播收益高达{效率}元/万播，是"小流量高变现"的典型代表。
```

## 七、数据处理流程

### Step 1：数据准备

```
输入文件：
├── 剧集数据统计.xlsx    # 包含每日收益、播放量等
├── works_list.csv       # 发布剧目列表
└── 剧目分类标签.csv     # 剧名-频道-题材映射
```

### Step 2：数据清洗

```python
# 注意单位转换
# 原始数据中广告收益可能是"分"，需转换为"元"
df['广告收益'] = df['广告收益'] / 100

# 计算万播收益
df['万播收益'] = df['广告收益'] / df['阅读量'] * 10000

# 处理无穷值
df['万播收益'] = df['万播收益'].replace([np.inf, -np.inf], np.nan)
```

### Step 3：聚合计算

```python
# 日频聚合
daily = df.groupby(['日期', '频道']).agg({
    '广告收益': 'sum',
    '阅读量': 'sum'
}).reset_index()

# 周频聚合
def get_week(date):
    day = date.day
    if day <= 5: return 'W1'
    elif day <= 12: return 'W2'
    elif day <= 19: return 'W3'
    elif day <= 26: return 'W4'
    else: return 'W5'

df['周'] = df['日期'].apply(get_week)
```

### Step 4：生成图表

使用 matplotlib 生成图表，保存为 PNG 格式，DPI 150。

### Step 5：生成报告

使用 python-docx 组装 Word 文档，插入图表和表格。

## 八、写作要点提醒

1. **图表为主，文字为辅**：每张图表后紧跟简明描述，不要冗长
2. **数据用加粗**：关键数据在正文中加粗突出
3. **客观叙事**：语句平实，避免主观评价和网络用语
4. **逻辑清晰**：按框架逐层展开，不跳级
5. **格式统一**：全篇字体、行距、缩进一套标准用到底
6. **图表不拆页**：图表与说明在同一页
